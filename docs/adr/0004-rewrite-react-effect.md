# Rewrite from scratch in React + Effect, deployed with Alchemy

The 2025 app (SvelteKit + Hono, ~35k lines) is replaced, not refactored: the data model changes completely (rulebook, divisions, command log) and the owner prefers the stack of his other projects (Bun, Effect on the server, React with Effect Atom on the client, Alchemy with Cloudflare OAuth) so that agents and he work the same way everywhere. The old app keeps running beside the new one until a rehearsal passes.
